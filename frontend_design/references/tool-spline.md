# Tool: Spline (No-Code 3D)

A browser-based, collaborative 3D editor built specifically for the web. Use it when a designer needs to ship an interactive 3D hero fast, without hand-coding Three.js.

## What it is

Spline gives you an orbit/pan/zoom viewport, an object hierarchy, and a properties panel — like Figma for 3D. Unlike Blender/Cinema 4D (which target film/games), Spline targets web embedding directly. Materials are physically based (roughness, metalness, and **transmission** for the popular frosted-glass look); HDRI environment presets do more for quality than manual lights. An Events panel lets you add interactivity (hover, click, scroll, mouse-follow) and camera states with no code.

## Designing scenes

- Keep geometry low-poly; the web pays for every triangle.
- Lean on environment/HDRI lighting before adding manual lights.
- Use built-in compression on export.
- Design a clear focal object rather than a busy scene — one strong 3D anchor beats clutter (and performs far better).

## Export and embed options

1. **Public URL / `<spline-viewer>` web component** — zero build; a `<script type="module">` plus `<spline-viewer url="…scene.splinecode">`. Works in plain HTML, Webflow, Framer, Squarespace.
2. **React** — `@splinetool/react-spline` + `@splinetool/runtime`:
   ```jsx
   import Spline from "@splinetool/react-spline";
   export default function Hero() {
     return <Spline scene="https://prod.spline.design/XXXX/scene.splinecode" />;
   }
   ```
3. **Next.js** — `@splinetool/react-spline/next` renders an autogenerated blurred placeholder server-side (better perceived load).
4. **Exported Three.js code** — for deep integration into an existing Three.js setup.

## Interactivity from code

The React wrapper is a thin layer over the vanilla runtime, so the full runtime API is available:
```jsx
function Hero() {
  const onLoad = (spline) => {
    const obj = spline.findObjectByName("Cube");
    obj.position.x = 2;
    spline.emitEvent("mouseDown", "Cube"); // trigger an editor-defined event
  };
  return <Spline scene="…/scene.splinecode" onLoad={onLoad}
                 onSplineMouseDown={(e) => console.log(e.target.name)} />;
}
```
`findObjectByName/ById`, mutate `position/rotation/scale`, listen to `onSplineMouseDown`/`Hover`, and `emitEvent(type, name)` to fire events defined in the editor.

## Performance and when to use vs hand-coded

- Spline scenes can add **2–5MB** and meaningful GPU load. Keep polys low, textures ≤1024², use compression, and **self-host the `.splinecode`** to avoid CORS.
- Render-on-demand is the default; **lazy-load** the component (`next/dynamic`, `ssr: false`) and provide a static-image fallback for low-end devices and reduced-motion users.
- **Use Spline when:** speed of iteration matters, a designer owns the scene, or you want interactivity without code.
- **Reach for hand-coded R3F/Three.js when:** you need fine performance control, custom shaders, to avoid the runtime weight, or tight integration with app state. See `tool-react-three-fiber.md` / `tool-threejs.md`.
- Always budget it against LCP/INP — a 3D hero must never block first paint. See `craft-performance.md`.
